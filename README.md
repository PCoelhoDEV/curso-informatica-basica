# Curso Prático de Informática Básica (Windows 10)

Página de vendas de alta conversão para o **Curso Prático de Informática Básica com Certificado de Conclusão de 40 Horas**.

## Estrutura do Projeto
- `index.html`: Landing page moderna, responsiva (Mobile-First) construída com Tailwind CSS e Lucide Icons.
- `jovem-emprego.jpg`: Imagem aspiracional de destaque do hero.
- `certificado-real.png`: Imagem oficial em alta definição do Certificado de 40h.
- `apostila-capa.png`: Mockup da capa da Apostila Oficial em PDF (45 páginas).
- `wiapy-capa-quadrada-1000x1000.png`: Capa do produto para Wiapy/Kiwify.
- `wiapy-banner-checkout-1920x600.png`: Banner de checkout.
- `netlify.toml`: Configuração de deploy direto no Netlify.
